# Gabarito – Avaliação Prática CARPRC2

Projeto de referência para a avaliação prática de Programação de Computadores 2.

Requisitos: Java 17+, MySQL 8+ e MySQL Connector/J.

1. Execute `sql/schema.sql`.
2. Ajuste usuário e senha em `src/main/java/dao/Conexao.java`.
3. Execute `Main.java`.

O projeto implementa histórico de transferências, Strategy de tarifas, transação JDBC, validações e interface Swing.
